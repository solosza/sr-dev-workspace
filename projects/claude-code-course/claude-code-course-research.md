# Claude Code Course Content — Research Report

## Executive Summary

**Verdict: The market is already saturated with generic Claude Code courses. The differentiated angle is autonomous agent governance — the kernel, pipelines, and self-building patterns — which no existing course covers.** Recommend a free content series (YouTube + written) for authority/lead gen rather than a paid course. The Isagawa kernel expertise is genuinely unique but the audience for it (advanced developers building production agent systems) is smaller than the "learn Claude Code basics" crowd.

### What Standard Courses Cover

Most courses cover the same ground:
1. Installation and setup
2. Basic commands and workflows
3. CLAUDE.md configuration
4. MCP server integration
5. Multi-tool use and context management
6. GitHub workflow automation
7. Custom commands and skills
8. Plan/Execute/Clear workflow patterns

### What NONE of Them Cover

- **Self-building agent governance** (hooks, gate enforcement, protocol creation)
- **Autonomous pipelines** (backlog → decompose → execute without human intervention)
- **Domain specs** (teaching agents to specialize in new domains)
- **Production testing** (modular test harness for agent output)
- **Attestation and provenance** (cryptographic proof of agent work)
- **Lessons and self-improvement** (agent learns from failures, updates its own rules)
- **Multi-repo orchestration** (cross-repo delegation, spec factory pattern)
- **Hook-enforced quality gates** (agent can't bypass its own rules)

**This is the gap.** No course teaches you to build a self-governing, self-improving agent system. They teach you to use Claude Code; Isagawa teaches you to build an autonomous engineering operation.

## 5. Defileo Course Analysis

The Defileo "0 to Claude Code expert in 7 days" free course serves as a lead generation funnel. Key observations:
- **Free** — no direct monetization, builds email list and authority
- **7-day email drip format** — daily lessons delivered via email
- **Beginner-focused** — "no coding background, no expensive tools, no fluff"
- **Goal:** Funnel subscribers into paid products, consulting, or premium community
- **Effectiveness:** Strong engagement signal (high X engagement on announcement)

**What Isagawa can learn:** The free drip model works for audience building. But Isagawa's content would target a different (more advanced) audience. The overlap is in format (free, structured, daily progression), not in content.
