## Hero Subheadline

## Hero Description
Isagawa Kernel is a self-building harness for Claude Code agents. It installs enforcement gates at the tool-call boundary — every write, every edit, every command passes through protocol checks that block non-compliant actions before they happen. When an agent fails, the failure is recorded as a permanent lesson and the protocol updates mechanically. The agent doesn't just follow rules. It builds them, enforces them, and improves them.
