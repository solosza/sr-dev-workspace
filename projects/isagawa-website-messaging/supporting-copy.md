## Feature Messaging Blocks

### Section 01: The Kernel (replaces "The Seed")

**Current:** Technical mechanism catalog (anchor tokens, gate enforcers, learn loops, session protocol)

**Proposed:** Lead with what the kernel does for the user, then explain how.

"The kernel is a set of interlocking enforcement mechanisms that govern every agent action. Hooks intercept tool calls at the boundary. Gates block non-compliant writes before they happen. Anchors force periodic protocol re-reads to prevent drift. And every failure records a lesson that updates the protocol permanently.

The result: governance that is a property of the system, not a layer on top of it."

**Subsection rewrites:**
- **Anchor Token** → "Every N actions, the system re-reads its own protocol. Context drift becomes mechanically impossible."
- **Gate Enforcer** → "A hook at the tool-call boundary blocks writes until prerequisites are met. The agent cannot proceed without passing the gate."
- **Learn Loop** → "Every failure is recorded as a permanent lesson. The protocol updates itself. The same mistake cannot recur."
- **Session Protocol** → "Start, anchor, work, complete. The same governed loop, every session, every agent."
