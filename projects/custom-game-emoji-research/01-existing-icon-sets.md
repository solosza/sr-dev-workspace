## 1. game-icons.net

**Scope:** 4,180+ free SVG and PNG icons, with new icons added weekly.

**Key Contributors:** Lorc (1,429 icons), Delapouite (2,022 icons), 40+ other contributors.

**Categories:** Broad coverage of fantasy/RPG themes including weapons, armor, creatures, spells, status effects, items, terrain, GUI elements, board/card game icons (116), and more. Tags are organized by singular keywords (e.g., "sword", "potion", "fire").

**License:** Creative Commons 3.0 BY (CC-BY 3.0). Free for commercial use with attribution: "Icons made by {author}. Available on https://game-icons.net"

**Formats:** SVG (primary, vector), PNG (rendered). Editable via Inkscape or their online Studio tool.

**Last Updated:** Continuously maintained; new icons added weekly.

**Strengths:** Largest single free collection. Black-and-white silhouette style is highly adaptable (stencils, gradients, paint-overs). Extensive coverage of traditional fantasy RPG categories.

**Weaknesses:** Monochrome silhouette style only — no color variants, no pixel art, no emoji-style rendering. Not specifically designed for grid-based tactical gameplay (no hex/grid tokens, no terrain overlays). Icons are general-purpose RPG, not optimized for small display sizes like emoji.

## Category Coverage Analysis

| Category | Well-Covered | Weak/Absent |
|----------|-------------|-------------|
| **Weapons** (swords, axes, bows) | Extensively covered everywhere | — |
| **Armor** (helmets, shields, chest) | Well-covered | — |
| **Potions/Consumables** | Well-covered | — |
| **Spells/Skills** | Moderate (game-icons.net, some itch.io) | Tactical spell indicators (AoE shapes, range) |
| **Monsters/Creatures** | Moderate (portraits/tokens) | Symbolic emoji-style monster icons |
| **Items/Loot** | Extensively covered | — |
| **Terrain Types** | Weak — mostly tile sets, not icons | Symbolic terrain emoji (lava, pit, wall, door) |
| **Status Conditions** | Weak — game-icons.net has some | Poisoned, stunned, prone, grappled as emoji |
| **Game Mechanics** | Very weak | Initiative, movement, range, cover indicators |
| **Environmental Hazards** | Very weak | Trap icons, hazard markers, zone effects |
| **Grid/Hex Tokens** | Weak — mostly character portraits | Symbolic action/state tokens for grid play |
| **Dungeon Features** | Weak as icons | Doors, chests, stairs, levers as emoji |
| **Emoji-Sized (≤64px)** | Moderate (pixel art packs) | Purpose-built emoji sets for chat/Discord |

**Key Gap:** No existing product provides a unified, emoji-style icon set specifically designed for grid-based tactical/dungeon gameplay. The market has abundant weapons/armor/item icons but lacks symbolic emoji for game mechanics (conditions, terrain, hazards, actions) at small display sizes. This is the primary opportunity space.
