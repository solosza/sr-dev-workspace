# Assay — AI-automation agency for local businesses (Claude + n8n)

**Date:** 2026-07-30 · **Source:** Bashar J Katou 6-step blueprint
**Verdict:** The literal blueprint is KILLED. Two reframes survive — and the winner uses *your* actual edge (governance).

## Plain answer
The generic "build Claude+n8n automations for local businesses" agency is **one of the most saturated plays of 2026** — thousands of operators, and the people teaching it (Katou, Ottley) make their money **selling the course, not running the agency.** That "seller-of-the-how-to, not the doer" tell is a big red flag. Killed.

But there's real value underneath (a laundry's n8n agent saved 130+ hrs/mo), and it survives two ways:
1. **Governed automations for a *regulated* local niche** (dental/medical/legal/financial) — where an **audit trail + human-approval is a real moat**, willingness-to-pay is higher, and the AAA crowd won't go (compliance is "boring/hard"). This is your fit-to-me edge: you own the kernel. **Rank 1.**
2. **One productized automation, one niche** (e.g. missed-call/booking agent) sold as a fixed package + recurring — because local businesses buy *packages, not bespoke*. Rank 2.

## Every idea this run (good & bad)
| # | Idea | Lens | Verdict |

| 1 | Generic bespoke AAA for local biz, cold outreach | literal | **KILLED** — 100% saturated, no moat, reachability, guru red-flag, thin economics |

## Under the hood
Normalized: value = local SMB saves time / better service · who-pays = SMB owner (re-examined: vendor / outcome) · mechanism = build automations, sell.
Gates that fired: **saturation** (100%), **legitimacy/doer-vs-seller** (guru red flag — new signal), **reachability** (local-SMB cold — same killer as the website run), **moat** (commodity n8n), **fit-to-me** (STRONG for the governed angle — you own the kernel).
Prior-art: adjacent to the local-website-agency run (same buyer, same reachability killer) — not a dup; reused that lesson.
**Decision:** kill the literal; conditional-green on #2 (governed niche) rank 1, #3 (productized) rank 2. Gated on a cheap pilot test.
