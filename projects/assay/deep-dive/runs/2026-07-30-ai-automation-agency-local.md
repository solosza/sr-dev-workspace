# Deep-Dive — Governed automation for a regulated local niche

**Date:** 2026-07-30 · **Business:** governed/productized automation, one regulated niche (e.g. dental)
**Verdict: GO-IF** — go only if a 30-day pilot lands one paying regulated client. The value is real and your governance edge is genuine; the unknowns are reach + willingness-to-pay at the pilot.

## Why
- **Market:** real demand (a single n8n agent saved a laundry 130+ hrs/mo); regulated niches have compliance budgets + stickier retention. Buyers want **fixed packages** ($1-3.5k setup, $500-1.5k/mo).
- **Economics:** productized package + recurring; governance justifies premium; margins strong once templated per niche. Works if reach holds.
- **Your edge is real, not a claim:** the kernel gives audit + mandatory HITL out of the box — the exact thing regulated buyers need and the AAA crowd lacks.

## Riskiest assumption + the test
**Assumption:** a regulated local niche will pay recurring for a governed automation AND you can reach them.
**Test (~30 days):** pick ONE niche (e.g. dental). Hand-build ONE governed automation (compliant recall/booking + audit log). Reach ~20-30 via a **warm/vertical channel** (association, vertical-SaaS partner, referral — NOT generic cold). **Pass = ≥1 paid pilot ($500-1.5k/mo) in 30 days.**

## Competition (from /competition)
Generic arena saturated; the regulated-niche + governance seam is defensible. Moat = governance + niche + outcome-guarantee.

## Risks / kill-conditions
- **Reachability** — solve via a vertical channel, not cold (the recurring killer).
- **Compliance liability** — the automation must PROPOSE, human APPROVES (never auto-act on a regulated decision); this is the firewall AND the selling point.
- **Kill if:** no paid pilot in 30 days, or you can't find a warm channel into the niche.

## If GO — first 90 days
1. Pick the niche + the one automation + the warm channel.
2. Build the governed MVP (kernel audit + HITL + n8n).
3. Land 1 paid pilot; prove hours-saved + zero compliance incidents.
4. Templatize; add 2-3 more clients same niche.
5. Start the receipts log (outcomes) — the moat.

**HITL:** commit (run the pilot) · park · kill.
