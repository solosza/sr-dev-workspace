## Key Observations

1. **Current messaging is already heavily "loops" framed.** The word "loop" or loop-adjacent concepts (cycle, recursive, re-read, "every session") appear in every section. The site already tells a loop story — it just doesn't use the word "loop" as prominently as it could.

2. **"Governance" is the dominant category** — it appears in every section and is the primary differentiator. The site positions Isagawa as a governance framework, not an agent builder.

3. **"Agent systems" language is secondary** — it appears mainly in Growth and Self-Extension sections. The site doesn't lead with "we build agent systems" — it leads with "we govern agent execution."

4. **Trust/provenance is powerful but rear-loaded** — the attestation proof and Rekor verification are at the bottom. This is the strongest "show don't tell" element on the page.

5. **The narrative arc (Seed → Growth → Self-Extension → This Page) is a loop story** — it describes the system building itself. This IS a loop narrative, even though it doesn't use the word.

6. **Prior messaging research (backlog 142) already shifted from "natural language compilation" to "SDD architecture"** — the current site reflects that pivot. The question now is whether to pivot further toward "loops and agent systems" framing.
