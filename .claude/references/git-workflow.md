# Git Workflow

## Branches
- `feature/` - New functionality
- `bugfix/` - Bug fixes
- `hotfix/` - Urgent production fixes

## Commits (Conventional)
- `feat:` - New feature
- `fix:` - Bug fix
- `refactor:` - Code restructuring
- `test:` - Test additions/changes
- `docs:` - Documentation
- `chore:` - Maintenance

## Rules
- Never commit directly to main
- No force pushes
- Squash before merge
