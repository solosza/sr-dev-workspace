# Distribution Angle-Loop

**Purpose:** For an idea, answer *"what lanes make this BIG?"* — the amplification engines, not the first-customer channel (`/gtm`'s job). Part of the `/expand` family.
**Philosophy:** generative — dream the reach engine; the adversarial loops test it.

## Cross-cutting rules
- **THINK BIGGER.** The reach machine — social-media lanes, a content engine, community, partnerships, marketplaces, virality — that scales the space, not one campaign.
- **LEAN OUTPUT** ([[loop-output-lean]]). **Standalone & modular.** **Generative, not kill-by-default.** **Every run saved.**
- **Capture new angles.** Spot a monetization/expansion path with NO existing angle-loop? Append it to `projects/assay/loop-candidates.jsonl` — `/sharpen` promotes recurring ones into new loops.

## Steps
| # | Step | Do |
|---|------|-----|
| 1 | Lanes | Which amplification lanes fit (YouTube/short-form, X, newsletter, SEO, community, partnerships, marketplaces, affiliates)? |
| 2 | The engine | The repeatable content/social motion that compounds attention (not a one-off). |
| 3 | Flywheel | How reach feeds the business feeds more reach (audience → product → audience). |
| 4 | Cheapest test | The smallest post/lane test to see if it pulls. |

## Output (lean)
1. **The 1-2 highest-leverage lanes.**
2. **The content/social engine** (the repeatable motion).
3. **The flywheel** (how it compounds).
4. **Cheapest test.** One line: pursue?

## Persist (compact)
- **Report** -> `projects/assay/distribution/runs/<YYYY-MM-DD>-<slug>.md`.
- **Ledger** -> `.claude/skills/distribution/state/ledger.jsonl` (idea, lanes, engine, flywheel, test, report path).
- **Venture record** -> add a Distribution-angle note to the venture.
