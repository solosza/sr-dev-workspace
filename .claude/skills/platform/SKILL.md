# Platform Angle-Loop

**Purpose:** For an idea, answer *"what layer could this own so others build on top?"* Part of the `/expand` family.
**Philosophy:** generative — dream the rails; the adversarial loops test it.

## Cross-cutting rules
- **THINK BIGGER.** From doing-the-work to owning-the-rails: the infrastructure, the standard, the marketplace, the API everyone in the space needs. The picks-and-shovels-but-you-own-the-mine play.
- **LEAN OUTPUT** ([[loop-output-lean]]). **Standalone & modular.** **Generative, not kill-by-default.** **Every run saved.**
- **Capture new angles.** Spot a monetization/expansion path with NO existing angle-loop? Append it to `projects/assay/loop-candidates.jsonl` — `/sharpen` promotes recurring ones into new loops.

## Steps
| # | Step | Do |
|---|------|-----|
| 1 | The layer | What repeatable capability could others (competitors even) build on — infra, standard, marketplace, API, certification? |
| 2 | Who builds on it | Who are the third parties, and why would they use your rails vs roll their own? |
| 3 | The take | How you monetize the platform (rev-share, subscription, transaction fee, certification). |
| 4 | Cheapest test | The smallest way to prove one third party wants the rails. |

## Output (lean)
1. **The rails** (what layer you'd own).
2. **Who builds on it + why.**
3. **The take** (how it monetizes).
4. **Cheapest test.** One line: pursue?

## Persist (compact)
- **Report** -> `projects/assay/platform/runs/<YYYY-MM-DD>-<slug>.md`.
- **Ledger** -> `.claude/skills/platform/state/ledger.jsonl` (idea, layer, builders, take, test, report path).
- **Venture record** -> add a Platform-angle note to the venture.
