# Productize Angle-Loop

**Purpose:** For an idea, answer *"what repeatable part becomes a product that scales without my time?"* Part of the `/expand` family.
**Philosophy:** generative — dream the leverage; the adversarial loops test it.

## Cross-cutting rules
- **THINK BIGGER.** From labor to leverage — the product/SaaS/template/tool that sells while you sleep and serves thousands off one build.
- **LEAN OUTPUT** ([[loop-output-lean]]). **Standalone & modular.** **Generative, not kill-by-default.** **Every run saved.**
- **Capture new angles.** Spot a monetization/expansion path with NO existing angle-loop? Append it to `projects/assay/loop-candidates.jsonl` (don't drop it) — `/sharpen` promotes recurring ones into new loops.

## Steps
| # | Step | Do |
|---|------|-----|
| 1 | The repeatable core | What part of the work is the same every time (the thing worth productizing)? |
| 2 | The product form | Product/SaaS/template/tool that delivers it self-serve. |
| 3 | Leverage | How it scales past your hours (1 build → many sales) + what stays human. |
| 4 | Cheapest test | Smallest way to prove people buy the product form (a pre-sold template, a landing page). |

## Output (lean)
1. **The repeatable core.**
2. **The product form.**
3. **The leverage** (why it scales).
4. **Cheapest test.** One line: pursue?

## Persist (compact)
- **Report** -> `projects/assay/productize/runs/<YYYY-MM-DD>-<slug>.md`.
- **Ledger** -> `.claude/skills/productize/state/ledger.jsonl` (idea, core, product_form, leverage, test, report path).
- **Venture record** -> add a Productize-angle note to the venture.
