# Stack Angle-Loop

**Purpose:** For an idea, answer *"once I own this customer, what else can I sell them?"* Part of the `/expand` family.
**Philosophy:** generative — dream the maximal lifetime value; the adversarial loops test it.

## Cross-cutting rules
- **THINK BIGGER.** Own the customer relationship, then stack — the next product, a bundle, a higher tier, a recurring add-on, the whole wallet-share of that customer.
- **LEAN OUTPUT** ([[loop-output-lean]]). **Standalone & modular.** **Generative, not kill-by-default.** **Every run saved.**
- **Capture new angles.** Spot a monetization/expansion path with NO existing angle-loop? Append it to `projects/assay/loop-candidates.jsonl` — `/sharpen` promotes recurring ones into new loops.

## Steps
| # | Step | Do |
|---|------|-----|
| 1 | The customer | Who you've won + what else they need in this space. |
| 2 | The stack | The next 2-3 things to sell them (product, bundle, tier, add-on, service). |
| 3 | LTV | How stacking multiplies lifetime value + retention (more hooks = stickier). |
| 4 | Cheapest test | Smallest cross-sell offer to an existing customer to see if they take it. |

## Output (lean)
1. **The won customer + their unmet needs.**
2. **The stack** (next things to sell).
3. **The LTV multiple.**
4. **Cheapest test.** One line: pursue?

## Persist (compact)
- **Report** -> `projects/assay/stack/runs/<YYYY-MM-DD>-<slug>.md`.
- **Ledger** -> `.claude/skills/stack/state/ledger.jsonl` (idea, customer, stack, ltv, test, report path).
- **Venture record** -> add a Stack-angle note to the venture.
