# Small (reframe loop)

**Purpose:** For an idea, answer *"what's the smallest, fastest, narrowest version that makes money?"* The subtractive twin of `/expand`.
**Philosophy:** generative but SUBTRACTIVE — strip, don't stack. Sometimes the winning move is a tiny wedge you can own this week, not the empire.

## Cross-cutting rules
- **THINK SMALL.** The smallest thing that works — one feature, one niche, one channel, one customer type. Fast to cash, cheap to test, easy to own. Ruthlessly cut.
- **LEAN OUTPUT** ([[loop-output-lean]]). **Standalone & modular.** **Generative, not kill-by-default.** **Every run saved.**
- **Capture new angles.** Spot a reframe/monetization path with NO existing loop? Append it to `projects/assay/loop-candidates.jsonl` — `/sharpen` promotes recurring ones.

## Steps
| # | Step | Do |
|---|------|-----|
| 1 | Smallest viable | The one-feature / one-outcome version that still delivers real value. |
| 2 | Narrowest niche | The tiniest, most specific customer you could totally own (a beachhead). |
| 3 | Fastest dollar | The quickest path to the first paying customer — this week, not this quarter. |
| 4 | Cut list | What to drop to get there (everything non-essential). |

## Output (lean)
1. **The small version** in one line.
2. **The beachhead niche** (narrowest ownable).
3. **Fastest path to $1** (the move).
4. **What to cut.** One line: pursue the small version?

## Persist (compact)
- **Report** -> `projects/assay/small/runs/<YYYY-MM-DD>-<slug>.md`.
- **Ledger** -> `.claude/skills/small/state/ledger.jsonl` (idea, smallest, beachhead, fastest_dollar, cut, report path).
- **Venture record** -> add a Small-angle note to the venture.

## Render the result (final step, optional)
After presenting, render the small version + beachhead as a live, question-able board via [[../render/steps/step-serve-and-watch]]: pass this loop's output through the adapter [[../render/adapters/INDEX]] (`to_items`), then serve-and-watch. Standalone and modular — the loop still runs headless without it. Plain vocabulary, no em dashes, fit as a tag only are baked into the adapter.

## Chain
Reframe trio: `/expand` (big) · **`/small` (small)** · `/lateral` (sideways). Run any on any idea.
