# License Angle-Loop

**Purpose:** For an idea, answer *"could I sell the SYSTEM instead of only running it?"* Part of the `/expand` family.
**Philosophy:** generative — dream others doing the work while you own the rails; the adversarial loops test it.

## Cross-cutting rules
- **THINK BIGGER.** Franchise the playbook, white-label the tech, license the brand/certification — armies of operators run it, you take a cut and own the standard.
- **LEAN OUTPUT** ([[loop-output-lean]]). **Standalone & modular.** **Generative, not kill-by-default.** **Every run saved.**
- **Capture new angles.** Spot a monetization/expansion path with NO existing angle-loop? Append it to `projects/assay/loop-candidates.jsonl` — `/sharpen` promotes recurring ones into new loops.

## Steps
| # | Step | Do |
|---|------|-----|
| 1 | The asset | What's licensable — the method, the tech/software, the brand, a certification? |
| 2 | The licensees | Who'd pay to run it (aspiring operators, agencies, incumbents in other regions)? |
| 3 | The model | Franchise fee + royalty · white-label subscription · certification/accreditation. |
| 4 | Cheapest test | Smallest way to prove one licensee wants in (a pre-sold pilot license). |

## Output (lean)
1. **The licensable asset.**
2. **The licensees + the model.**
3. **The scale** (how many could run it).
4. **Cheapest test.** One line: pursue?

## Persist (compact)
- **Report** -> `projects/assay/license/runs/<YYYY-MM-DD>-<slug>.md`.
- **Ledger** -> `.claude/skills/license/state/ledger.jsonl` (idea, asset, licensees, model, test, report path).
- **Venture record** -> add a License-angle note to the venture.

## Chain
`/expand` -> **`/license`** (one angle).
