# /expand

Think BIGGER on an idea — the generative counterweight to the adversarial pipeline. Dispatches an idea through the expansion angle-loops to find how big it can get.

## Usage

```
/expand <business or idea>
```

| Argument | Purpose | Example |
|----------|---------|---------|
| `<idea>` | The idea/venture to expand | `/expand governed automation for dental offices` |

## What It Does

Looks at an idea and asks *how big can this get?* — suggests which expansion angles fit (`/data`, `/distribution`, `/platform`, `/productize`, `/license`, `/stack`, `/adjacent`), runs or queues them, then synthesizes the biggest coherent vision (the empire version) + the highest-leverage next move. Generative, ambitious — NOT kill-by-default (the adversarial loops test what survives). Output = quickest view. Saved (report + ledger + venture record).
