# /small

Think SMALL — the smallest viable, narrowest, fastest-to-cash version of an idea. The subtractive counterweight to `/expand`.

## Usage

```
/small <business or idea>
```

## What It Does

Strips an idea to the smallest thing that makes money — the narrowest lucrative niche, the one-feature version, the fastest path to a first dollar this week. Sometimes the win is going smaller (a wedge you can actually own now), not empire. Generative, not kill-by-default. Output = quickest view. Saved (report + ledger + venture record).
