# /launch

Ship the first sellable asset — smallest thing that delivers the promise. Post-GO loop.

## Usage

```
/launch <business>
```

| Argument | Purpose | Example |
|----------|---------|---------|
| `<business>` | The committed business to build + launch | `/launch faceless hustle-content channel` |

## What It Does

Defines the MVP (smallest sellable unit), reuses-first (what existing assets/tools already cover it), plans build-vs-buy, sets the HITL/automation line (what a human approves), runs a launch checklist, and a go-live test that the thing actually delivers the promised value once. Kill-by-default if the core value can't be delivered. Output = quickest view. Every run saved (report + ledger + index + venture record).
