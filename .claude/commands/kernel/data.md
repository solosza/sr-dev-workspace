# /data

Expansion angle — turn the data an idea generates into an asset, revenue, or moat.

## Usage

```
/data <business or idea>
```

## What It Does

Asks: what data does this generate, is it valuable + to whom, and how do you monetize it (sell it, productize it, a benchmark, a data moat/network effect). Think-bigger, generative. Output = quickest view. Saved (report + ledger + venture record).
