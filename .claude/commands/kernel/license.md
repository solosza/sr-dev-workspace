# /license

Expansion angle — license the method, tech, or brand to others (franchise / white-label).

## Usage

```
/license <business or idea>
```

## What It Does

Asks: could you sell the SYSTEM instead of only running it — franchise the playbook, white-label the tech, license the brand/certification? Others do the work, you own the rails. Think-bigger, generative. Output = quickest view. Saved (report + ledger + venture record).
