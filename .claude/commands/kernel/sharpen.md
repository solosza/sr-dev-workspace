# /sharpen

Read outcomes across the loops and upgrade the engines — the meta/learn loop.

## Usage

```
/sharpen
```

(No argument — reads the ledgers + venture records.)

## What It Does

Reads the loop ledgers + venture outcomes (what was predicted vs what actually happened), finds the misses (a killed idea that would've worked; a GO that flopped; a copyable "moat"), extracts the pattern, and proposes a concrete engine upgrade (a new lens, a new gate, a threshold change) — then applies it or queues it for approval. This automates the manual v2 tuning. Output = quickest view (the misses + the proposed upgrades). Every run saved (report + ledger).
