# /stack

Expansion angle — adjacent revenue on the SAME customer (cross-sell, bundle, upsell).

## Usage

```
/stack <business or idea>
```

## What It Does

Asks: once you own this customer, what else do they need that you can sell them — the next product, a bundle, a higher tier, a recurring add-on? Maximize lifetime value per customer already won. Think-bigger, generative. Output = quickest view. Saved (report + ledger + venture record).
