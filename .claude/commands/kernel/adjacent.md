# /adjacent

Expansion angle — adjacent VENTURES in the same space (new businesses to own), fed back to `/assay`.

## Usage

```
/adjacent <business or idea>
```

## What It Does

Asks: what OTHER businesses live next to this one in the same space — same customer, same capability, same data, same channel — that you could also own? Maps the adjacent territory, then hands the best candidates to `/assay` to vet as their own ventures. Think-bigger, generative. Output = quickest view. Saved (report + ledger).
