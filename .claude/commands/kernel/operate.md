# /operate

Run the live business, HITL-governed. Post-GO loop — the kernel's home turf (govern-by-default, not kill-by-default).

## Usage

```
/operate <business>
```

| Argument | Purpose | Example |
|----------|---------|---------|
| `<business>` | The live business to run | `/operate faceless hustle-content channel` |

## What It Does

Defines the repeating operation (the fulfill -> deliver -> bill loop), sets the HITL checkpoints (every step PROPOSES, a human APPROVES — no auto-act on a real decision), the metrics to watch, exception handling, the cadence, and a continuous-improvement hook. This is the governed operating layer — gated outputs + human-review checkpoints + an audit ledger. Output = quickest view (a run-state view). Every run saved (report + ledger + index + venture record).
