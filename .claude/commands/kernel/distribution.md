# /distribution

Expansion angle — the lanes (content, social, channel) that amplify an idea to scale.

## Usage

```
/distribution <business or idea>
```

## What It Does

Finds the amplification lanes — social-media engines, content, community, partnerships, marketplaces — that get the idea BIG (not just the first customer, which is `/gtm`'s job). Think-bigger, generative. Output = quickest view. Saved (report + ledger + venture record).
