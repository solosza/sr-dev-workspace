# /gtm

Find the channel + funnel that actually gets customers. Post-GO loop, highest-leverage (distribution decides).

## Usage

```
/gtm <business>
```

| Argument | Purpose | Example |
|----------|---------|---------|
| `<business>` | The committed business to take to market | `/gtm faceless hustle-content channel` |

## What It Does

Picks the 1-2 channels where the ICP actually is (not all of them), sharpens the hook/message, maps the funnel (awareness -> action), designs the outreach/content mechanic, and sets the first-customer test with a response/CAC threshold. Kill-by-default if no channel you can actually run reaches the buyer (the reachability killer). Carries heavier HITL — every spend/outreach step proposes, human approves. Output = quickest view. Every run saved (report + ledger + index + venture record).
