# /competition

Map the competitive field for a chosen business and find where you win. Loop A of the venture-loop family (runs after `/assay` picks an idea).

## Usage

```
/competition <business or wedge>
```

| Argument | Purpose | Example |
|----------|---------|---------|
| `<business>` | The chosen business/wedge to size up | `/competition local AI receptionist for mobile mechanics` |

## What It Does

Takes one chosen business, scopes the rival set (5-10), profiles them, runs the arena structure (Porter's Five Forces + your SWOT), and — the point — finds the **actionable gaps** (underserved segments, pricing holes, service weaknesses, positioning white space) and your defensible angle to win. Kills by default if the arena is entrenched with no seam. Output is the **quickest view to the pertinent info**, never a long doc. Every run is saved (report + ledger + index).
