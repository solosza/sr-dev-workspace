# /gaps

Idea-hunter — find underserved segments + "everyone dies on X, so X is the opportunity". Part of the `/source` family.

## Usage

```
/gaps <seed theme or space>
```

## What It Does

Takes a seed and finds the underserved segments, the jobs no one serves well, and the recurring failure point everyone hits (mined from the kill-patterns / anti-library) — because the thing that keeps killing ventures is often the real opening. Dedups against the assay ledger, ranks, feeds `/assay`. Lean output, saved.
