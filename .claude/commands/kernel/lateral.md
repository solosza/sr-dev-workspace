# /lateral

Think OUT OF THE BOX — the unconventional, contrarian, assumption-breaking angle. The lateral counterweight to the obvious.

## Usage

```
/lateral <business or idea>
```

## What It Does

Names the obvious approach, then deliberately breaks it: invert the core assumption, recombine with something unrelated, do the opposite of what everyone else does, find the angle nobody would think of. Generative, not kill-by-default. Output = quickest view. Saved (report + ledger + venture record).
