# /offer

Design the offer + pricing that captures the most value, honestly. Post-GO loop (runs after `/deep-dive` says go).

## Usage

```
/offer <business>
```

| Argument | Purpose | Example |
|----------|---------|---------|
| `<business>` | The committed business to package + price | `/offer faceless hustle-content channel` |

## What It Does

Picks the value metric (what you charge for), designs the packaging (tiers/bundles/free-vs-paid), sets price points against benchmarks + willingness-to-pay, chooses the model (one-time vs recurring vs hybrid), adds risk-reversal (trial/guarantee), and names the cheapest price/offer test. Kill-by-default if no viable price clears margin. Output = quickest view, never a long doc. Every run saved (report + ledger + index + venture record).
