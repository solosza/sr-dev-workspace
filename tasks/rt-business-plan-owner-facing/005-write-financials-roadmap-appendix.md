# Task 005: Financial Plan + Roadmap + Appendix
**Type:** BUILD | **Gates:** OB-05
## Action
Write Financial Plan/Projections, Pricing, Funding, the phased Roadmap, and Appendix sections.
## Spec
**Financial Plan / ROI:** avoided cost (fewer denied claims, fewer clawbacks, audit protection), modeled plainly against the manual cost; the per-claim/per-year dollar figure is owner-to-confirm (the facility's own billing staff are the credible source) — do NOT fabricate. **Pricing:** flat monthly per-facility fee recommended (simple, predictable for a single facility); exact figure set with the owner. **Funding:** the ask if any (pilot terms; equity/monthly comp context from the venture baseline, high level). **Roadmap (plain):** Phase 1 = the compliance check (now); later phases add help with building the patient list, drafting the charting for the therapist to sign, and preparing the bill for a person to approve — every step reviewed and approved by a person, and the application never submits a bill by itself. **Appendix:** the four things to confirm before launch (a signed data agreement, access to the EMR's data, an accuracy check against the therapist's judgment, and confirming the audit record meets Medicare's needs), plus a pointer to the internal strategy brief for the detailed sourcing.
## Acceptance
Sections written; ROI honest (unverified = owner-to-confirm); roadmap phased + plain with the human-approval + never-auto-submit guarantees; four preconditions listed.
