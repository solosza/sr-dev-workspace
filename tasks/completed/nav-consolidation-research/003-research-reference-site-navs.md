# Research: Reference Site Navs (Linear, Vercel, Stripe, Anthropic)

**Type:** RESEARCH
**Phase:** 1
**Depends on:** 001

## Goal

Study how leading monochrome/minimal engineering sites handle nav when they have many items. These are the reference points for the isagawa.co aesthetic standard.

## Sites to Study

1. **linear.app** — nav structure, item count, how products/features are grouped
2. **vercel.com** — product nav, "Resources" or dropdown groupings
3. **stripe.com** — multi-product nav consolidation approach
4. **anthropic.com** — minimal nav, how they handle multiple product/research sections
5. **planetscale.com** or **railway.app** — smaller monochrome engineering sites with product range

## For Each Site, Note

- Total nav item count (desktop)
- Which items are always visible vs in a dropdown
- Label used for the collapsed group (Products, More, Work, Resources, etc.)
- Mobile nav behavior
- Any "active page" indicator pattern

## Output

Write findings to `projects/nav-consolidation-research/02-reference-sites.md`

Include:
- Per-site observations
- Common patterns across sites
- Takeaway for isagawa.co
