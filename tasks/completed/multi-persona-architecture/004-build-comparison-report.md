# Task 004: Build Comparison Report

## Type
BUILD

## Objective
Synthesize research from tasks 001-003 into a final comparison report with clear recommendation and implementation roadmap.

## Steps
1. Read outputs from tasks 001-003
2. Build comparison matrix:
   - State isolation
   - Complexity / maintenance burden
   - Scalability (adding new personas)
   - Autonomous operation feasibility
   - Code reuse vs duplication
   - Hook enforcement complexity
   - Inter-persona communication
3. Make recommendation with rationale
4. Write implementation roadmap for winning approach:
   - Phase 1: what to build first
   - Phase 2: what follows
   - Prerequisites and blockers
5. Include architecture diagrams for recommended approach

## Deliverable
`projects/multi-persona-architecture/04-comparison-report.md`

## Acceptance Criteria
- Side-by-side comparison matrix (Approach A vs B)
- Clear recommendation with technical justification
- Implementation roadmap with phases
- Concrete file paths, command names, state schemas for recommended approach
