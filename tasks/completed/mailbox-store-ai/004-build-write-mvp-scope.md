# 004 — Write MVP Scope Definition

## Type
BUILD

## Action
Based on research from tasks 001-002, write the MVP scope definition. Must answer:

1. **First agent to build** — which agent has highest ROI? (likely: customer communication or package intake)
2. **Core features for MVP** — minimum set of features that provide value to a store owner
3. **Tech stack** — recommended stack (e.g., Python/FastAPI backend, Twilio for SMS, carrier APIs, SQLite/PostgreSQL)
4. **Integration requirements** — what must connect to what? (POS system, carrier APIs, notification services)
5. **Timeline estimate** — rough phases (week 1-2: core engine, week 3-4: carrier integration, etc.)
6. **What's NOT in MVP** — explicitly list deferred features
