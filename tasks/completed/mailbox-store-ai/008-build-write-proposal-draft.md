# 008 — Write 1-Page Proposal Draft

## Type
BUILD

## Action
Write a concise 1-page proposal that could be shown to potential mailbox store owner customers. This is a sales/pitch document, not a technical document.

Structure:
1. **Headline** — compelling value proposition (e.g., "AI-Powered Operations for Your Mailbox Store")
2. **The Problem** — 2-3 sentences on what store owners struggle with daily
3. **The Solution** — what the product does, in plain language (no jargon)
4. **Key Features** — 4-5 bullet points of the most impactful features
5. **How It Works** — 3-step simplification (sign up → connect → automate)
6. **Pricing** — starting price, what's included
7. **Call to Action** — next step for interested store owners

## Constraints
- Must be under 100 lines
- Write for a non-technical mailbox store owner audience
- Focus on time saved and revenue impact, not technology

## Target File
`docs/research/mailbox-store-ai-proposal.md`

## Acceptance
- [ ] Under 100 lines
- [ ] Non-technical language throughout
- [ ] Specific value proposition (not generic "AI will help you")
- [ ] Clear call to action
