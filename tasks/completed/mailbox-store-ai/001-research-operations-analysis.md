# 001 — Research Mailbox Store Operations

## Type
RESEARCH

## Action
Research mailbox store operations to understand the full workflow, pain points, and technology landscape. Use web research to gather data on:

1. **Core operations** — package intake (scan, photograph, notify), mailbox rental lifecycle (assignment, renewal, expiration, key management), shipping label generation and rate comparison across carriers
2. **Customer service** — walk-in inquiries, phone/text automation, new customer onboarding (ID verification, CMRA form 1583), notary scheduling
3. **Business management** — revenue tracking per service line, customer retention, peak time prediction, multi-location challenges
4. **Technology landscape** — POS systems used (PostalMate, PackageLog, Corelytics), carrier APIs (USPS Web Tools, UPS Developer Kit, FedEx API, DHL Express), typical hardware (label printers, barcode scanners, cameras)
5. **Biggest time sinks** — what consumes most of the owner's day?

## Web Research Queries
- "mailbox store POS software" / "pack and ship store software"
- "USPS Web Tools API" / "UPS developer API" / "FedEx REST API"
- "mailbox store operations workflow"
- "CMRA form 1583 process"

## Target File
`docs/research/mailbox-store-ai-operations.md`

## Acceptance
- [ ] File covers all 5 areas listed above
- [ ] Includes at least 3 POS/management software options with names
- [ ] Includes carrier API details (endpoints, auth, rate limits)
- [ ] Identifies top 3 time sinks for store owners

## Dependencies
