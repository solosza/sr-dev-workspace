# 005 — Write Pricing Model

## Type
BUILD

## Action
Based on competitor pricing (task 003) and opportunity assessment (task 002), define the pricing model for selling to other mailbox store owners.

Include:
1. **Pricing tiers** — at least 2 tiers (e.g., Basic, Pro) with feature differentiation
2. **Pricing structure** — monthly SaaS, per-location, per-transaction, or hybrid
3. **Price points** — specific dollar amounts with rationale (anchored to competitor pricing and value delivered)
4. **Revenue projections** — at 10, 50, 100 customers
5. **Free trial / onboarding** — strategy for getting first customers
6. **Upsell path** — how does Basic → Pro → Enterprise work?

## Target File
`docs/research/mailbox-store-ai-pricing.md`

## Acceptance
- [ ] At least 2 pricing tiers defined
- [ ] Specific dollar amounts per tier
- [ ] Revenue projection table
- [ ] Competitor price comparison

## Dependencies
002, 003
