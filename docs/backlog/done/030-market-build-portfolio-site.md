# AI Portfolio Site

## Status
Open

## Priority
High — needed before job applications (backlog 029 feeds into this)

## Summary
Build a polished portfolio site that tells the story of the Isagawa Kernel and the AI management layer. Not a generic dev portfolio — a targeted showcase for AI agent infrastructure roles at top companies. Should demonstrate systems thinking, builder velocity, and the depth of what was shipped. Research existing developer portfolio sites for inspiration, pick a tech stack, then build.

## Phases

### Phase 1: Research
- Survey 10-15 standout developer/engineer portfolio sites (especially AI/infra people)
- Identify patterns: what works, what's cringe, what hiring managers actually look at
- Collect URLs of the best examples for reference
- Determine must-have sections vs nice-to-have

### Phase 2: Design decisions
- Pick tech stack (static site generator, framework, hosting)
- Define site structure and sections
- Decide on visual style — technical credibility, not flashy
- Plan content: what to write, what to link, what to demo

### Phase 3: Build
- Implement the site
- Write content from the innovation inventory + resume
- Link to repos, demo videos if applicable
- Deploy to hosting (GitHub Pages, Vercel, Netlify, or custom domain)

### Phase 4: Review + ship
- Get feedback
- Polish
- Connect to resume and job applications

## Requirements
- Must showcase the AI management layer / Isagawa Kernel as the centerpiece
- Must link to actual repos (isagawa-co, isagawa-qa) as evidence
- Must position for agent infrastructure / harness engineering roles, not QA
- Must be honest — show what was built, not hype what it isn't
- Should include: system overview, key capabilities, portfolio evidence (repo count, spec count, platforms), career background
- Should NOT be a wall of text — needs visual hierarchy, diagrams, or interactive elements
- Should work well on mobile (hiring managers review on phones)
- Must have a custom domain or at minimum a clean URL
