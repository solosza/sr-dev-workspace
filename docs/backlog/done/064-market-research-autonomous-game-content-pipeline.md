# Research Autonomous Game Content Pipeline

## Status
Open

## Priority
High — the backlog/execute-pipeline loop already works autonomously; applying it to game content creation across major platforms is a direct monetization path with massive scale potential

## Summary
Research how the existing kernel pipeline (backlog → task-builder → run-task.sh) can be pointed at game content creation for top platforms like Roblox, Fortnite, Minecraft, etc. The loop already runs autonomously — the question is what game assets, mods, packs, maps, and UGC it can produce, what the monetization channels look like per platform, and what the unit economics are when an AI agent is cranking these out at scale with zero marginal labor cost.

## Requirements

### Platform Landscape
- Which platforms have the largest UGC/creator economies? (Roblox, Fortnite Creative, Minecraft Marketplace, Steam Workshop, Unity Asset Store, Unreal Marketplace)
- What are the revenue share models per platform? (Roblox DevEx rates, Epic creator payouts, Minecraft Partner Program, etc.)
- Which platforms allow programmatic/automated content submission?
- What are the content policies and review processes — any restrictions on AI-generated content?

### Content Types per Platform
- **Roblox:** games, game passes, developer products, clothing/accessories, plugins
- **Fortnite Creative / UEFN:** islands, maps, prefabs, devices, cosmetic concepts
- **Minecraft:** skins, texture packs, worlds, add-ons, mash-up packs (Marketplace Partner Program)
- **Steam Workshop:** mods for popular games (Cities Skylines, Factorio, Stardew Valley, etc.)
- **Asset stores:** 3D models, shaders, scripts, sound packs (Unity/Unreal)
- What can be fully generated by code/AI vs what requires manual art/3D work?

### Pipeline Fit Assessment
- Map the current kernel pipeline to game content: backlog item = content idea, tasks = asset creation steps, run-task.sh = autonomous execution
- What domain specs would be needed? (e.g., roblox-lua-game spec, fortnite-uefn spec, minecraft-addon spec)
- What toolchain gaps exist? (3D modeling, texture generation, audio, playtesting)
- Can the vibe-coder repo be leveraged for the code-generation parts?

### Monetization Model
- Revenue per asset type per platform (what sells, what doesn't)
- Volume economics — if the pipeline produces N assets/day, what's the expected revenue curve?
- Long-tail vs hit-driven — do game assets follow power law or steady state?
- Competitor landscape — who else is doing AI-generated game content at scale?

### Legal and Platform Risk
- Platform ToS on AI-generated content — any bans or restrictions?
- IP/copyright considerations for generated assets
- Account risk — can platforms ban creators for automated submission?
- Tax and payment processing per platform

## Validated Data Points (from X posts, April 2026)

### Fortnite Map Creator — @theparuchh / @0xWast3
- Epic Games pays $350M/year to Fortnite map creators
- One creator: never opened the game, ran a Python pipeline on Claude API, shipped 10 maps in a week, pulled $4,200/month
- Revenue model: Epic pays creators based on how long players stay on their maps
- Full pipeline, prompts, and code shared publicly — reverse-engineerable

### Roblox Creator Economy — @starmexxx (April 2026)
- **$1.5B paid to creators in 2025** (first time crossing $1B, up 31% YoY)
- Top 10 creators averaged $38.5M/year; top 1,000 averaged $1.3M/year
- 380M monthly active users, 151M daily active users (up 70% YoY)
- Platform revenue: $4.9B, Q4 2025 growth 43% YoY
- **Claude Code + Roblox Studio MCP** — 54 tools, writes Luau directly into live Studio session
- Developer built complete mining tycoon (currency, shop, rebirth, DataStore) in 2 hours with Claude — zero scripting experience
- Tycoon genre has highest monetization: 45-90 min sessions, progress addiction loop
- Revenue tiers: new tycoon $50-500/mo, established $500-5K/mo, top 10% $5K-50K/mo, viral $100K+/mo
- Game Pass monetization: 300 Robux VIP pass × 10 sales/day = ~$342/mo from one pass
- Creator Rewards formula rewards daily active spenders, returning users, session time
- 33% of earning creators never took a CS class
- "Steal a Brainrot" — built in 4 months, hit 25M concurrent players, all-time platform record
- **MCP setup:** `claude mcp add robloxstudio -- npx -y robloxstudio-mcp@latest`
- CLAUDE.md template for Luau strict mode, Roblox services, architecture patterns included
- Roblox's own Luau Assist: 50%+ of new Studio sessions use AI features

### Implications for Pipeline Research
- Roblox is the strongest first-target platform: highest payouts, most automation-friendly (Claude writes Luau directly via MCP), proven $1.5B creator economy
- Fortnite is validated second target: $350M/year payouts, Python pipeline already proven
- The kernel pipeline maps directly: backlog = game concept, tasks = build systems (currency, upgrades, leaderboard, daily login, game passes), run-task.sh = autonomous execution
- Domain spec needed: roblox-luau-tycoon spec with CLAUDE.md, MCP setup, architecture patterns
