# Positioning — What Isagawa Is

## Status
Reference — creative brief for all site copy

## The Single Framing

> Isagawa is a conversational agent factory.

"Factory" says what it does — you talk, it builds. Not a framework you configure, not a platform you deploy to. A factory: raw material (your words) goes in, structured artifacts come out. The conversation IS the interface.

What makes this factory different: **it extends itself.** Two properties most factories don't have:

1. **The factory governs itself mechanically.** Not prompt-based guardrails, not observability — runtime hooks at the tool-call boundary that block with UUID-gated tokens. Governance is a property of the factory, not a layer on top of it.
2. **The factory extends itself.** New capabilities produced by the factory become part of the factory. The loop closes.

## Five Views, One Product

| View | What it actually describes |
|------|--------------------------|
| Automation workflow | What running the factory looks like from outside |
| AI management layer | What the governance kernel provides at runtime |
| Spec-driven development | The format the factory speaks internally |
| Agent factory | One application of the factory (producing workspaces) |
| Agent governance platform | The property that makes everything else trustworthy |

These aren't five products. They're five elevations of one product. The site leads with the single framing; each sub-framing appears as a feature, not a competing identity.

## Hero-Level Copy

"Isagawa is a conversational agent factory. You describe intent in natural language; the factory produces structured artifacts, including new capabilities, under mechanical governance; those capabilities become part of the factory and extend what future intent can produce."

## Feature Decomposition

- How does it extend itself? Backlogs → tasks → governed execution → new capabilities.
- How do you keep it from going off the rails? Mechanical governance at the tool-call boundary.
- What does a user do? Describe what they want. In words.
- Who is it for? Engineers who want to stop typing and start describing.

## Category Fit

"Harness" places Isagawa in the conversation Factory and Cognition are already in. The differentiator is the modifier — "self-extending" — not the noun. Riding an emerging term as it gains adoption is easier than creating one from scratch.
