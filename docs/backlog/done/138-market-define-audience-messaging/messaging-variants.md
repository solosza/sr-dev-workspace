## Format
For each persona, develop:
1. **Core value prop** (one sentence)
2. **Extended positioning** (2-3 sentences)
3. **Key benefit phrases** (3-5 short phrases that resonate)
4. **Example use case** (real-world scenario)
5. **Call to action** (tailored next step)
