# Research Claude Code Course Content

## Status
Open

## Priority
Medium — lead generation and authority building; validates whether educational content is a viable channel

## Summary
Research creating a structured educational course or tutorial series for Claude Code expertise. Study the Defileo "0 to Claude Code expert" 7-day free course as a reference model. Determine whether Isagawa should create similar content — either free (lead gen / authority) or paid (direct revenue) — and what format, platform, and curriculum would work best.

## Requirements

### Reference Analysis
- Study the Defileo 7-day course structure — what topics does it cover, what's the progression?
- What platforms host it? (Email drip, Notion, Gumroad, own site, YouTube series)
- What's the monetization model? (Free as lead gen? Paid? Upsell to consulting?)
- What makes it effective or not?

### Curriculum Design
- What should a Claude Code course cover? (Setup, CLAUDE.md, MCP, tools, workflows, agents, automation)
- Beginner vs intermediate vs advanced tracks
- How does Isagawa's kernel/pipeline expertise differentiate from generic "how to use Claude Code" content?
- Unique angles: autonomous pipelines, self-building agents, domain specs, production testing

### Platform & Format
- Course platforms: Teachable, Gumroad, Udemy, own site, YouTube, email drip
- Video vs written vs hybrid
- Free tier (authority/lead gen) vs paid tier (revenue)
- How to leverage the portfolio site (isagawa.co) as the landing page

### Market Assessment
- How many Claude Code courses/tutorials exist today?
- What's the demand signal? (Search volume, X engagement, community questions)
- Who's the target audience? (Developers, non-technical founders, QA engineers, DevOps)
- Pricing benchmarks for AI tool courses
