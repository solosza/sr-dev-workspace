# On-Prem LLM Market Shift — Isagawa Pivot + Personal Skill Path

## Status
Open

## Priority
High — active job search + potential strategic pivot; market timing matters if enterprise IP fears are accelerating on-prem adoption

## Summary
Companies are increasingly worried that frontier model providers are absorbing their IP through API usage, and are looking for ways to use LLMs without sharing proprietary data — one prominent solution being owning GPUs and hosting local/on-prem LLMs. Research whether this shift is real and sized, then answer two pivot questions: (1) how Isagawa can profit from it (products, services, positioning), and (2) how the user personally acquires these skills for job hunting and career leverage.

## Requirements
- Validate the trend: evidence that enterprises are moving to on-prem/local LLM hosting over IP/data-sharing fears (surveys, spend data, vendor moves, regulated-industry drivers like healthcare/defense/finance)
- Map the solution landscape: own-GPU on-prem, private cloud/VPC hosting, open-weight models (Llama, Mistral, Qwen, etc.), inference stacks (vLLM, TGI, Ollama, llama.cpp), enterprise platforms (NVIDIA NIM, Databricks, etc.)
- Isagawa pivot analysis: concrete offerings (e.g., on-prem agent harness deployments, kernel-governed local LLM automation, QA platforms running against local models, consulting/integration for regulated clients), fit with existing assets (Isagawa Kernel MIT, QA platforms, agent orchestration expertise), competition, realistic entry paths
- Personal skill path: what to learn (GPU infra, model serving, quantization, fine-tuning, RAG on-prem, security/compliance), certifications or portfolio projects that signal these skills, which job roles/titles demand them (with examples), how this stacks with the existing AI-harness job search (pipeline 029)
- Deliverable: research report with a recommended pivot decision (go/no-go/watch), top 3 Isagawa opportunities ranked, and a personal 30-60-90 skill plan with portfolio project suggestions
